## 1. Justificación de la Decisión del Stack Multiplataforma

### Desktop (PC Windows, macOS, Linux)
- **Stack:** Electron 44 + Node.js 20/22 + TypeScript 5.9 + React 19 + Tailwind CSS v4 + Vite 8.
- **Razón:** Acceso directo a disco con APIs nativas de Node.js, velocidad de desarrollo en React 19, integración de editores de alto nivel (CodeMirror 6 y Milkdown) y empaquetado multi-OS con `electron-builder` (`.exe`, `.dmg`, `AppImage`).
- **Alternativas Descartadas:** WPF/.NET (limitado a Windows), Qt/C++ (desarrollo lento de interfaces fluidas).

### Mobile (Android & iPhone / iOS)
- **Stack:** Flutter 3.24+ + Dart 3.5+ (Material 3 & Cupertino).
- **Razón:** Rendimiento nativo a 120 FPS, acceso a Scoped Storage / DocumentPicker sin puentes lentos, y un solo código base para compilar tanto en Android como en iOS/iPhone.
- **Alternativas Descartadas:** React Native (mayor consumo de memoria y puentes serializados lentos para I/O masivo de archivos).
