## 1. Flujos Críticos de Tarea (Task Flows)

### Flujo A: Creación y Enlace de Notas en Desktop
1. Usuario presiona atajo `Ctrl+N` / `Cmd+N`.
2. Escribe el título de la nota y selecciona carpeta de destino.
3. El editor CodeMirror 6 genera el frontmatter YAML automáticamente.
4. Al escribir `[[`, se despliega el menú contextual de autocompletado de notas existentes.
5. Al pegar una imagen, se copia automáticamente a `attachments/` y se inserta el enlace relativo.
6. Guardado automático instantáneo al pausar la escritura.

### Flujo B: Registro Rápido de Serie en el Gimnasio (Móvil)
1. Usuario abre NoteVault en Android/iOS y toca "Entrenamiento".
2. Toca el ejercicio actual (ej. "Sentadilla con Barra").
3. Se despliegan las series previas y los campos numéricos de peso y repeticiones.
4. Ingresa `100 kg` y `8 reps` y presiona "Marcar Serie".
5. Se actualiza el JSON del día en disco y se activa un temporizador de descanso de 90 segundos con vibración háptica.

## 2. Marco Conceptual: Flujo de Interacción de Usuario

<div class="entity-card">

1. **Entidad principal e independiente.**
2. **Es la entidad líder del conjunto de datos:** posee un identificador global único que modela el camino crítico del usuario (`user_flow_id`: `FLOW-MOBILE-WORKOUT-LOG`) consultado en las pruebas de usabilidad.
3. **Existe por sí misma en el diseño de interacción sin depender del layout de pantalla**, y es la única responsable de garantizar que una tarea crítica se complete en menos de 3 toques o 5 segundos.
4. **Punto de entrada y límite de consistencia:** Si un flujo introduce más de 3 pasos para una acción recurrente, se rediseña por fricción excesiva.
