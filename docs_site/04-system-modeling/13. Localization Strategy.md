## 1. Estrategia de Internacionalización y Adaptación Cultural

NoteVault está diseñado para operar con absoluta naturalidad lingüística y precisión numérica en múltiples regiones e idiomas:

### 1.1 Soporte Multilingüe
- **Idioma Primario:** Español (`es-ES`, `es-LATAM`) para la interfaz, ayudas contextuales y documentación canónica.
- **Idioma Secundario:** Inglés (`en-US`) disponible mediante diccionarios JSON desacoplados (`locales/es.json`, `locales/en.json`).
- **Separación Estricta de Texto:** Ninguna cadena de texto visible para el usuario se encuentra codificada directamente (*hardcoded*) en los componentes React o widgets Flutter.

### 1.2 Formato Determinista de Fechas y Horas
- **Persistencia en Disco:** Formato canónico ISO 8601 estricto (`YYYY-MM-DD` y `YYYY-MM-DDTHH:mm:ssZ`) para garantizar ordenamiento lexicográfico y compatibilidad con herramientas de sincronización.
- **Visualización en Interfaz:** Uso de la API estándar `Intl.DateTimeFormat` configurada con el locale del usuario para mostrar fechas amigables (ej. "Martes, 20 de Octubre de 2026").
- **Preservación de Zona Horaria:** Todas las alarmas de tareas y cálculos de rachas de hábitos se computan sobre la medianoche local del dispositivo, evitando desfases por cambios de meridiano.

### 1.3 Formato Numérico y Monetario
- **Finanzas Multidivisa:** Soporte configurable para símbolos de moneda (`$`, `€`, `£`, `COP`, `MXN`).
- **Aritmética Decimal Exacta:** Almacenamiento en centavos enteros (`integer cents`) para evitar desbordamientos de coma flotante en los presupuestos.

## 2. Marco Conceptual: Estrategia de Localización

<div class="entity-card">

1. **Entidad principal e independiente.**
2. **Es la entidad líder del conjunto de datos:** posee un identificador global único (`locale_profile_id`: `LOC-ES-CO-UTC-5`), invocado por los formateadores de fecha, moneda y diccionarios de traducción.
3. **Existe por sí misma en la configuración de preferencias sin depender del idioma del contenido de las notas**, y es la única responsable de garantizar que los textos y números se presenten bajo las convenciones culturales elegidas por el usuario.
4. **Punto de entrada y límite de consistencia:** Si una clave de traducción no existe en el idioma secundario, recurre de forma determinista a la clave equivalente en el idioma primario (*fallback language*).
