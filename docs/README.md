# Notas internas de trabajo

Esta carpeta guarda las **notas internas de trabajo** del equipo: planes, guías de diseño, prompts para asistentes de IA y registros de decisiones. Están mezcladas en español e inglés y reflejan el estado del proyecto en cada momento, así que **pueden estar desactualizadas**.

La documentación oficial para personas usuarias y desarrolladoras está en <https://lessteps.com/docs/> (fuente en [`docs_site/`](../docs_site/)). El formato de la bóveda, que sí se mantiene al día, es [`VAULT_FORMAT.md`](VAULT_FORMAT.md).
