# Internal working notes

This folder holds the team's **internal working notes**: plans, design guides, prompts for AI assistants and decision records. They are a mix of Spanish and English and reflect the state of the project at the time, so **they may be outdated**.

The official documentation for users and developers is at <https://lessteps.com/docs/> (source in [`docs_site/`](../docs_site/)). The vault format, which is kept up to date, is [`VAULT_FORMAT.md`](VAULT_FORMAT.md).
