# English study system — ASSUMPTIONS log

Every ambiguous decision taken while building English as a second domain (phases 6–13), with the reason. Nothing
here was asked back to the user; each entry can be reversed by changing the one place named.

## Domains (phase 6)

1. **The existing skill set stays as is and becomes math-only in effect.** Mathematics (and, untouched,
   programming) keep their skills, prompts, topic types and default `_skills`; English gets its own catalogue with
   its own ids, so nothing is shared. `core/practice/mathGolden.test.ts` freezes what mathematics produces (catalogue,
   topic types, every prompt, the default skill notes) — it passes unchanged, which is the proof that mathematics did
   not move. Programming was outside the brief, so it was left alone.
2. **Domain = subject.** `domainOfSubject()` maps `english/ingles/inglés` → english, `programming*` → programming and
   anything else → math (the pre-existing behaviour for unknown subjects; unchanged).
3. **English has a branch, not a topic type.** Branches: grammar, writing, reading, listening, speaking. Vocabulary is
   NOT a branch. An English topic never gets `topic_type`.
4. **No default for languages.** A topic is classified by `branch:` in its `.practica.md` or by a branch folder in its
   path (`Inglés/3 Lectura/…`). Otherwise it is *unclassified*: it is logged in
   `.notevault/estudio/clasificacion-pendiente.json`, the AI/plan calls refuse with an explicit message, and the topic
   view shows a banner to pick the branch (`study_topic_classify`). A name-based **suggestion** is offered but never
   applied. Where mathematics still uses "mixed" as its fallback, it is unchanged.
5. **English exercises cannot take a maths mode** (and English-only modes are rejected in other subjects):
   `modeFor` throws instead of falling back to `solve`. Existing first-generation English modes (`translate`,
   `rewrite`, `writing`, `cloze`, `explain`, `true_false`, `find_error`) stay valid so old exercises keep working
   (`disciplineCatalog` still lists them), but they are no longer offered in the English catalogue.
6. **Difficulty 1/2/3 = CEFR A2/B1/B2+.** Session parameters (difficulty, quantity, hints, "hints don't count") are
   the same code as mathematics; `noBeginner` and `noHelper` flags express per-skill rules.

## Catalogue (phase 7)

7. **Ids are namespaced** (`gr_`, `wr_`, `rd_`, `ls_`, `sp_`, `vc_`), 34 skills: grammar 6, writing 6, reading 6,
   listening 5, speaking 6, vocabulary 5. They live in one pure table (`lib/englishSkillData.ts`) read by the UI and
   the core, so the two cannot drift.
8. **Vocabulary skills fit every branch**; a branch skill fits only its own branch. When a branch topic's skills are
   recommended by default, only its own branch's are (vocabulary is chosen, not assumed).
9. **Speaking has no speech recognition.** The learner speaks aloud and types a transcript / self-report; that text is
   what is graded. `sp_*` skills are therefore text exercises whose framing says so.
10. **Listening audio** is played by the app (browser speech synthesis or the media player) and the text stays
    hidden; `ls_dictation`, `ls_gap` and `vc_recall` are always without help (a hint would give the answer away).

## Structure (phase 8)

11. **Layout.** `Inglés N/<1 Gramática | 2 Escritura | 3 Lectura | 4 Escucha | 5 Habla>/<N.M tema>/`, plus
    `Vocabulario/` (the word bank's home, NOT a branch: it is excluded from the space map and the outline).
    Topics keep the mathematics file conventions: theory named after its folder, `.practica.md`, review file in
    `Repaso/`, exercises in `Ejercicios/<skill>/`.
12. **One syllabus per branch** (one AI call each, with that branch's brief), topics renumbered by the app
    (`N.1`, `N.2`… — the model's numbering is not trusted). The scope text may name branches ("solo lectura y
    escucha"); none named → all five. Topic names are in English (the learner studies English); explanations in
    Spanish.
13. **Default `_skills` per domain.** `ensureDefaultSkills(root, folder, refresh, subjectId)`: an English space gets
    `ENGLISH_DEFAULT_SKILLS` (theory contract kept identical so the topic map still builds), a mathematics space gets
    `DEFAULT_SKILLS` unchanged. A sibling space's `_skills` are inherited only from a space of the SAME domain (its
    subject is read from its overview; an unreadable overview still counts for mathematics, as before).
14. **No "all skills" default for English.** A practice file with no skills gets its branch's skills, or none when it has
    no branch (previously any subject fell back to every skill of the subject).

## Generation, vocabulary, reviews, dictation and maps (phases 9–13)

15. **Exercise framing per branch (phase 9).** English exercises are generated by `englishExercises.ts`, never by the
    mathematics prompt. Each competency carries its own act, judging criterion and answer kind; difficulty 1/2/3 is
    CEFR A2/B1/B2+. `grading.ts` has no fallback to the mathematics grader for English.
16. **Vocabulary practice (phase 10).** Vocabulary sessions (`vc_*`) take their words from the single word bank
    (`sessionWords`: due words first, then new ones) and are stored in `<space>/Vocabulario/Ejercicios/<skill>/`. The
    exercise records the words it used in a `words:` frontmatter field. That is an approximation: an exercise is graded
    as a whole, so every word of a passed exercise is counted as recalled and every word of a failed one as forgotten.
17. **Dictation.** The audio text is sent to the renderer (it is needed to speak it) but is only displayed after the
    exercise is graded; hiding it is UI-level, not a security boundary.
18. **Vocabulary reviews (phase 11) — pilot scope widened.** Reviews were topic-level. Words now have their own ladder
    [1, 3, 7, 14, 30, 60] days (a failure returns to tomorrow), shown in the review calendar (chips, add-word form,
    reschedule) and grouped into ONE reminder item per day so the notifier does not spam. Words without a date get one
    the first time they are practised. This widens the review scope beyond topics; mathematics reviews are unchanged.
19. **Dictation from the player (phase 12).** The "Dictado" button takes the cue being played (joined with the next when
    very short, ≤220 characters, ±0.3 s margin) and writes an `ls_dictation` exercise into the topic
    `<space>/4 Escucha/Dictados del reproductor`. Audio: the original clip when the media is inside the vault, otherwise
    the app's voice reads the subtitle. No English subtitles (or no English space) returns `{ ok: false, message }`, and the
    player keeps working.
20. **Concept maps (phase 13).** Drawn with no AI, written once when the English space gets its vocabulary home and never
    overwritten (edits are respected): `1 Gramática/00 Mapa de tiempos verbales.canvas` (past/present/future timeline,
    nine tenses, arrows say WHEN one is chosen) and `Vocabulario/00 Mapa de familias de palabras.canvas` (a starter set of
    three families; arrows carry the suffix). Word families are a built-in seed, not derived from the word bank, because
    the bank stores no derivations.

## First content of the English space (authored by hand)

21. **Content authored by Claude, not by the study AI, to save the learner's AI tokens.** `Inglés/` has 5 branches with 3
    topics each (levels A2–B2): 14 topics were written by hand following the space's own `_skills` contract (theory
    with the exact headings, `.practica.md` with branch + competency matrix, topic canvas from `kb_canvas`, branch and
    space maps, outline, 56 words in the shared bank). Topic `5.3 Giving an opinion` was generated by the study AI
    (deepseek-flash) through the app as the one end-to-end test: it produced theory, map and a speaking-only matrix.
22. **Observed gap in AI generation.** The generated 5.3 note omitted `level:` and got `difficulty: 1`; the app does not
    depend on it. Not fixed: the field is informational.
23. **Practice exercises were written by hand** (one per branch: gr_cloze, wr_paragraph, rd_skim_scan, ls_dictation,
    sp_guided) and loaded through `practice_load` in the real app (discipline, CEFR level, hidden audio text and
    `nohelp` for dictation confirmed). Grading was NOT exercised, because it calls the study AI.
24. **Fixed while testing:** the topic view told English learners to practise «problemas básicos o cálculo mental».

## Rethink: six areas, per-branch competencies (user feedback, 2026-09-30)

25. **Vocabulary is now the sixth area** (`6 Vocabulario`, branch `vocabulary`), with its own syllabus of word classes
    (common verbs, everyday nouns, adjectives, adverbs, phrasal verbs, collocations, fixed expressions). This reverses item 11
    ("vocabulary is not a branch"). The old `Vocabulario/` folder is merged into `6 Vocabulario/` once (files that already exist
    there are never overwritten). Vocabulary skills (`vc_`) are still offered to the other branches for their new words.
26. **Vocabulary sessions take ONE word class** (`sessionWords`): the class named by the topic ("6.1 Common verbs" → verb), or
    the class with most words due; if the bank has none of it, the whole bank. The class is the word's `part_of_speech`
    normalised (`verb, noun, adjective, adverb, phrasal verb, expression, other`).
27. **Grammar runs A1 → B1** (15 topics: to be … relative clauses). Exercise difficulty is now RELATIVE to the topic's level
    (`level:` in the practice file): 2 = the topic's level, 1 = a step below, 3 = a step above, never below A1
    (`cefrForTopic`). A topic with no level keeps the old A2/B1/B2.
28. **New competencies (47 in total, was 34).** Grammar: `gr_syntax` (analyse the structure), `gr_expressions`. Reading:
    `rd_paraphrase`, `rd_translate`. Listening: `ls_podcast`, `ls_shadowing`. Speaking, phonology: `sp_phonemes`, `sp_ipa`,
    `sp_word_stress`, `sp_sentence_stress`, `sp_intonation`, `sp_connected`. Vocabulary: `vc_synonyms`. All still without speech
    recognition: speaking exercises are typed self-reports.
29. **A topic with no declared skills is offered the first 6 of its branch** by the deterministic selector (cap
    `MAX_RECOMMENDED_SKILLS`); the real matrix comes from the plan (AI or hand-written), so branches with 8–12 skills need one.
30. **Player exercises.** The player now makes three kinds: dictation, shadowing (`ls_shadowing`, repeat the phrase) and podcast
    comprehension (`ls_podcast`, ~45 s, gist + details + summary). They go to the topics `4.5 Shadowing…` and `4.4 Podcasts…`
    when the space has them (otherwise to `Dictados del reproductor`). Podcast/shadowing have no auto-graded answer key: the
    transcript is the reference the grader compares with.
31. **Hand-written content (Claude, not the study AI):** 45 topics with theory, practice plan and map (grammar 15, writing 3,
    reading 5, listening 5, speaking 10 with `5.10` from the study AI, vocabulary 7) and ~150 words in the bank with classes.
    Topics renamed to fit the new numbering (e.g. `1.1 Present simple vs present continuous` is now `1.6`); a backup of the
    previous state is in `.trash/_respaldo_ingles_antes_de_6_areas_2026-09-30`.
32. **UI:** the LaTeX drawing tool is hidden when the open note belongs to an English space (and closes if it was open); the
    area/subject summary no longer shows the global "Errores frecuentes" log (the topic practice view keeps its own).
