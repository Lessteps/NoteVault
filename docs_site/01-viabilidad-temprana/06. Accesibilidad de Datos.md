# 06. Accesibilidad de Datos

**Fase:** 01 — Viabilidad Temprana  
**Entregable:** 06  
**Proyecto:** NoteVault (PC, Mac, Android, iPhone)

---

## 1. Disponibilidad y Accesibilidad del Almacenamiento

- **Fuente de la Verdad:** El sistema de archivos del sistema operativo anfitrión. No se requieren APIs de terceros ni datos externos propietarios para el arranque.
- **Estructura Abierta:** Todos los archivos de usuario son archivos estándar `.md` (Markdown con frontmatter YAML) o archivos `.json` formateados con indentación estándar de 2 espacios.
- **Interoperabilidad:** Si NoteVault deja de ejecutarse, el usuario puede abrir, leer y editar el 100% de sus notas y configuraciones con cualquier editor de texto plano (VS Code, Obsidian, Notepad, Vim).
- **Cero Dependencia de Terceros:** El sistema no depende de bases de datos externas caídas, servidores sin servicio o cierres de empresas de software.

---

## 2. Marco Conceptual: Accesibilidad Abierta de Datos

<div class="entity-card">

1. **Entidad principal e independiente.**
2. **Es la entidad líder del conjunto de datos:** posee un identificador global único que fija la garantía de no dependencia de datos propietarios (`data_accessibility_id`: `DATA-OPEN-FILESYSTEM`) consultado en las auditorías de portabilidad.
3. **Existe por sí misma en el contrato de arquitectura sin depender de la aplicación instalada**, y es la única responsable de asegurar que el formato de datos sobreviva a la aplicación que lo creó.
4. **Punto de entrada y límite de consistencia:** Prohíbe cualquier serialización binaria propietaria u ofuscada en disco.
