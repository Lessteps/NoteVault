# 1.10 Inducción matemática

## Idea en una frase
Para demostrar que una afirmación vale para todos los enteros a partir de $n_0$, basta probar que vale en $n_0$ y que, siempre que vale para un entero, también vale para el siguiente.

## Intuición
Imagina una fila infinita de fichas de dominó numeradas 1, 2, 3, … Para estar seguro de que caerán todas no necesitas mirarlas una a una: te bastan dos garantías. La primera, que alguien empuja la ficha 1. La segunda, que las fichas están colocadas de forma que *cualquiera* que caiga derriba a la siguiente. Con esas dos garantías, la 1 derriba a la 2, la 2 a la 3, y así sin fin: no queda ninguna en pie.

La inducción traduce esa imagen a una lista de afirmaciones $P(1), P(2), P(3), \dots$. El caso base es el empujón inicial. El paso inductivo no dice que alguna ficha caiga: es una promesa condicional, «si cae la $k$, cae la $k+1$», y se demuestra para una $k$ arbitraria. Por eso en el paso se *supone* $P(k)$ (la hipótesis inductiva) sin saber todavía si es cierta: solo se estudia qué pasaría si lo fuera.

Si falta cualquiera de las dos partes, el argumento no sirve: sin empujón no cae nada aunque las fichas estén bien colocadas, y con empujón pero con dos fichas demasiado separadas la cadena se corta. La inducción fuerte es la misma idea cuando una ficha necesita que caigan *varias* anteriores para caer ella.

## Definición formal
**Principio de inducción (principle of mathematical induction).** Sea $P(n)$ una afirmación sobre los enteros $n \ge n_0$. Si

1. $P(n_0)$ es verdadera (**caso base**), y
2. para todo entero $k \ge n_0$ se cumple $P(k) \Rightarrow P(k+1)$ (**paso inductivo**),

entonces $P(n)$ es verdadera para todo entero $n \ge n_0$. En símbolos:

$$\Big(P(n_0) \wedge \forall k \ge n_0\,\big(P(k)\Rightarrow P(k+1)\big)\Big) \Rightarrow \forall n \ge n_0\; P(n).$$

**Inducción fuerte (strong induction).** Si $P(n_0)$ es verdadera y, para todo entero $k\ge n_0$, se cumple $\big(P(n_0)\wedge P(n_0+1)\wedge\cdots\wedge P(k)\big) \Rightarrow P(k+1)$, entonces $P(n)$ es verdadera para todo entero $n\ge n_0$.

## Notación
- $P(n)$: la afirmación que depende de $n$; se lee «P de n». Para cada $n$ debe ser una proposición: verdadera o falsa.
- $n_0$: el primer entero para el que se afirma $P$; el caso base se prueba exactamente en $n_0$.
- $k$: un entero **arbitrario** con $k \ge n_0$, usado en el paso inductivo.
- **HI** (hipótesis inductiva): la suposición $P(k)$ —o $P(n_0),\dots,P(k)$ en inducción fuerte— dentro del paso inductivo.
- $\sum_{i=1}^{n} a_i$: la suma $a_1 + a_2 + \cdots + a_n$, notación habitual en las afirmaciones que se prueban por inducción.

## Ejemplos
### Ejemplo 1 — Una suma
$P(n)$: $1+2+\cdots+n = \frac{n(n+1)}{2}$ para $n\ge1$. Base: $1 = \frac{1\cdot2}{2}$. Paso: si vale para $k$, sumar $k+1$ a ambos lados da $\frac{k(k+1)}{2}+(k+1) = \frac{(k+1)(k+2)}{2}$, que es $P(k+1)$. Encaja en la definición: base en $n_0=1$ y paso probado para un $k$ arbitrario. Es [[1.10-T01 Suma de los primeros n naturales]].

### Ejemplo 2 — Una desigualdad con base distinta de 1
$P(n)$: $n! > 2^n$ para $n \ge 4$. Base: $4! = 24 > 16 = 2^4$. Paso: si $k! > 2^k$ con $k\ge4$, entonces $(k+1)! = (k+1)\,k! > (k+1)\,2^k \ge 2\cdot 2^k = 2^{k+1}$. Muestra que $n_0$ no tiene por qué ser 1: para $n=1,2,3$ la afirmación es falsa ($3! = 6 < 8$).

### Ejemplo 3 — Inducción fuerte
$P(n)$: todo entero $n\ge2$ es producto de primos (un primo cuenta como producto de un solo factor). Base: $2$ es primo. Paso: si $k+1$ es primo, ya está; si no, $k+1 = ab$ con $2\le a,b\le k$, y por la HI fuerte $a$ y $b$ son productos de primos, luego $k+1$ también. Aquí no basta suponer $P(k)$: se necesitan $P(a)$ y $P(b)$ para valores anteriores cualesquiera.

## No-ejemplos
### No-ejemplo 1 — Comprobar muchos casos
Verificar que $n^2+n+41$ es primo para $n=0,1,\dots,39$ no demuestra nada sobre todos los $n$: no hay paso inductivo. De hecho, para $n=40$ vale $1681 = 41^2$. Falta la parte 2 de la definición.

### No-ejemplo 2 — Paso sin caso base
$P(n)$: $n = n+1$. El paso «funciona»: si $k=k+1$, sumando 1 queda $k+1=k+2$. Pero no existe ningún $n_0$ con $P(n_0)$ verdadera, así que no se concluye nada. Falta la parte 1.

### No-ejemplo 3 — Paso que parte de lo que quiere probar
Escribir $P(k+1)$, manipularlo hasta llegar a $0=0$ y declarar el paso probado. Eso solo muestra que $P(k+1)$ implica algo verdadero, lo que no dice nada; el paso exige demostrar $P(k) \Rightarrow P(k+1)$.

## Resultados clave
- [[1.10-T01 Suma de los primeros n naturales]] — la suma $1+2+\cdots+n$ vale $\frac{n(n+1)}{2}$ para todo $n\ge1$.
- [[1.10-T02 Desigualdad de Bernoulli]] — $(1+x)^n \ge 1+nx$ si $x\ge-1$ y $n\ge1$ es entero.

## Errores comunes
- **No usar la HI.** Si el paso inductivo no utiliza $P(k)$ en ningún momento, o la prueba era directa (y sobraba la inducción) o hay un error. Señala con «por HI» la línea donde se usa.
- **Probar la implicación al revés.** Partir de $P(k+1)$ y deducir $P(k)$ no sirve; la cadena va de $k$ a $k+1$.
- **Olvidar el caso base o probarlo en el $n_0$ equivocado.** El paso puede ser válido para una afirmación falsa (No-ejemplo 2).
- **Inducción fuerte con bases insuficientes.** Si el paso usa $P(k-1)$ además de $P(k)$, hacen falta dos casos base; si no, la cadena no arranca.
- **Paso que falla para el primer $k$.** El paso debe valer para *todo* $k\ge n_0$, incluido $k=n_0$: es el error de «todos los caballos son del mismo color».

## Tarjetas
### T1 · definicion
**P:** Enuncia el principio de inducción (débil) con sus dos partes.
**R:** Si $P(n_0)$ es verdadera y para todo $k\ge n_0$ se cumple $P(k)\Rightarrow P(k+1)$, entonces $P(n)$ vale para todo $n\ge n_0$.

### T2 · definicion
**P:** ¿Qué cambia en la inducción fuerte respecto a la débil?
**R:** En el paso se suponen $P(n_0),\dots,P(k)$ —todos los casos anteriores—, no solo $P(k)$, para deducir $P(k+1)$.

### T3 · notacion
**P:** ¿Qué es la hipótesis inductiva y dónde se usa?
**R:** Es la suposición $P(k)$ (o $P(n_0),\dots,P(k)$) para un $k$ arbitrario; se usa solo dentro del paso inductivo, para deducir $P(k+1)$.

### T4 · estrategia
**P:** ¿Cuándo conviene la inducción fuerte en lugar de la débil?
**R:** Cuando $P(k+1)$ depende de casos anteriores distintos de $k$: por ejemplo, al factorizar $k+1=ab$ o en recurrencias que usan $k$ y $k-1$.

### T5 · ejemplo
**P:** Da una afirmación que se prueba por inducción con caso base $n_0 \ne 1$ y explica por qué.
**R:** $n! > 2^n$ para $n\ge4$: es falsa para $n=1,2,3$ ($3! = 6 < 8$), así que la base debe ser $n_0=4$.

### T6 · contraejemplo
**P:** ¿Por qué comprobar muchos casos no demuestra un «para todo $n$»? Da un ejemplo.
**R:** Porque falta el paso inductivo. $n^2+n+41$ es primo para $n=0,\dots,39$, pero en $n=40$ vale $41^2$.

### T7 · hipotesis
**P:** Muestra con un ejemplo que el caso base no se puede omitir.
**R:** Para $P(n)$: $n=n+1$, el paso vale ($k=k+1 \Rightarrow k+1=k+2$), pero $P$ es falsa para todo $n$: sin base no hay conclusión.

### T8 · error
**P:** ¿Dónde falla la «prueba» de que todos los caballos son del mismo color?
**R:** En el paso de $k=1$ a $k+1=2$: los dos grupos de $k$ caballos, $\{c_1\}$ y $\{c_2\}$, no se solapan, así que ningún caballo común transmite el color.

### T9 · conexion
**P:** ¿Qué relación hay entre la inducción y el principio del buen orden?
**R:** Son equivalentes: cada uno se demuestra a partir del otro. El buen orden dice que todo subconjunto no vacío de $\mathbb{N}$ tiene un mínimo.

### T10 · enunciado
**P:** Enuncia la desigualdad de Bernoulli con sus hipótesis.
**R:** Si $x\ge-1$ es real y $n\ge1$ es entero, entonces $(1+x)^n\ge 1+nx$.
