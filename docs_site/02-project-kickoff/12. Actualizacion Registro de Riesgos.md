## 1. Actualización de Riesgos Técnicos en Kickoff

| ID | Riesgo | Estado Post-Kickoff | Medida Preventiva Implementada |
| :--- | :--- | :--- | :--- |
| **RSK-06** | **Incompatibilidad de paquetes npm en React 19:** Que librerías Markdown o editores no soporten React 19. | Mitigado | Se validaron e integraron `@milkdown/kit` y `@codemirror/state` con soporte verificado en `package.json`. |
| **RSK-07** | **Desfase en la paridad de características móviles:** Que el cliente móvil se retrase frente al rápido desarrollo de escritorio. | Controlado | Se priorizó el desarrollo de los 4 módulos esenciales de movilidad: Tareas, Hábitos, Gym y Finanzas. |
| **RSK-08** | **Desbordamiento de memoria por indexación en vivo:** Que el explorador consuma excesiva RAM al cargar miles de notas. | Mitigado | Implementación de límite de escaneo `MAX_SCAN_NOTES = 4000` y lectura por demanda de árbol. |
